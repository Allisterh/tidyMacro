Validation

tidyMacro against the reference MATLAB and Stata codes

Each method in tidyMacro was run on the package datasets and compared with the different set of code suits in MATLAB and STATA.

Two kinds of objects are compared:

  • Deterministic objects (point estimates, standard errors, analytic confidence bands, FEVDs) are compared cell by cell. Max abs diff is the largest absolute difference over all variables, shocks and horizons.
  • Monte Carlo objects (bootstrap bands, posterior medians and credible bands) cannot agree draw by draw, because the two codes use different random number generators. Their gap is compared with the gap between two runs of the same code under different seeds. Same distribution means tidyMacro and the reference differ no more than each differs from itself.

Monte Carlo rows report the largest absolute gap between tidyMacro and reference bands at 1,000 draws (2,000 for the moving-block bootstrap, 10,000 for the long-run bootstrap). Going from 1,000 to 10,000 long-run draws shrank the tidyMacro-Toolbox gap 3.3 to 5.7 times, at least the √10 ≈ 3.2 that pure Monte Carlo error predicts. The LP-IV first-stage F differs only in its degrees of freedom: tidyMacro uses n − kcontrols − kz, the Toolbox n − kz.
